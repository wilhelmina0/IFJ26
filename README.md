# IFJ26

Týmový projekt pro IFJ/IAL 2026 - překladač IFJ26

Implementace překladače v jazyce C ze zdrojového jazyk IFJ26 do cílového jazyka IFJcode26.

## Struktura
- `src/` - zdrojový kód překladače
- `tests/` - testy + testovací data
- `docs/` - dokumentace

## Build a spuštění
Build a spuštění přes příkaz `make`, vyčištění build directory přes `make clean`, build + spuštění python skriptu (test.py) přes `make test`.
